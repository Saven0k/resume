# Резюме Романа Савенкова

Компактное адаптивное резюме на русском и английском в виде листа A4. Обычные HTML, CSS и JavaScript, без зависимостей и сборки. Все навыки собраны под Frontend; добавлены Agile, Waterfall, Jira, GanttPRO и data-driven подход.

Проектный опыт: Gallery (публичный репозиторий ArtGallary) и Digital Control. Описания основаны на портфолио и исходниках проектов; бронзовое место на чемпионате «Профессионалы» в 2025 году подтверждено публикацией колледжа. Результаты в процентах и размер пользовательской аудитории не заявлены без исходных данных.

## Локальный запуск

Установленный Node.js: `npm start`, затем открыть http://127.0.0.1:4173.

Проверка: `npm test`.

## Фотография

Добавьте свой снимок в `assets/photo.jpg` и замените `src="assets/photo.svg"` на `src="assets/photo.jpg"` в `index.html`. Фото автоматически заполнит отведённое место. Заглушка сейчас находится в `assets/photo.svg`.

## Редактирование

- Русский текст и ссылки: `index.html`.
- Английский перевод: объект `english` в `script.js`.
- Цвета и адаптивная вёрстка: `styles.css`.
- Возраст указан по исходному резюме; при необходимости обновите оба языка.

## GitHub Pages

В настройках репозитория: **Settings → Pages → Deploy from a branch → main → / (root)**. Файл `.nojekyll` позволяет публиковать страницу без Jekyll. Сборка и GitHub Actions не нужны.

## Печать

Откройте страницу на нужном языке и нажмите **Ctrl+P** (на macOS — **Cmd+P**). Выберите A4, книжную ориентацию и масштаб 100%, отключите колонтитулы браузера. Для PDF выберите «Сохранить как PDF». Стили печати скрывают переключатель языка и используют две колонки независимо от размера экрана.
